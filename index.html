ABOUT THE PROJECT

Forensic reasoning, translated into computer vision.

EXUV-Doc explores an evidence-oriented approach to secure-document authentication. Instead of reducing examination to a single black-box label, the system localizes named security features, preserves modality-specific observations and presents findings for examiner review.

The current implementation uses the 500 Saudi Riyal banknote as a controlled case study with paired visible and 365 nm ultraviolet imagery.

AI should support the forensic examiner—not replace the examiner’s judgment.

RESPONSIBLE USE

Decision support, not automated forensic authority.

EXUV-Doc is a research and examiner-support environment. Automated detections, confidence values and evidence summaries should not be treated independently as definitive legal conclusions, laboratory accreditation or substitutes for a complete forensic examination. Image quality, acquisition conditions, document condition and model limitations can affect observations.

FAQ

Questions, answered clearly.

Does the system simply classify a document as genuine or counterfeit?

No. Its central purpose is feature-level examination. It localizes individual security characteristics and presents evidence for review.

Why use both visible and UV images?

Different security features are revealed under different imaging conditions. The paired workflow preserves complementary visible and 365 nm UV evidence.

What does the confidence threshold mean?

It is the minimum model confidence required for a detection to be accepted. Lower values may detect more features but increase false detections; higher values are more selective.

Can the generated report be treated as an official forensic report?

The PDF is an AI-assisted examination record. Official use depends on the competent authority’s procedures, validation requirements and applicable evidentiary rules.
